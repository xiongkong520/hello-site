这个网页是怎么上线的

  1. 本地写好这几个文件（index.html 就是全部）
  2. git push 到 GitHub 仓库
  3. Cloudflare Pages 监听这个仓库，自动拉取并发布
  4. 以后每次 push，网站自动更新 —— 这就是 CI/CD 最小的样子

下一步

改标题、换颜色、加一张图片，然后 git commit + git push。几十秒后刷新网址，你会看到自己的改动真的上线了 —— 这一步的爽感是入门的关键。
