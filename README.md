# 转盘 · 自己定选项

> 一个不用登录、不用后端、打开就能用的随机转盘。选项自己填，存在本地，可以生成分享链接发给别人。

**在线体验 → https://mimichong.pages.dev/wheel/**

---

## 它是干什么的

纠结今天吃什么、谁去拿快递、抽个倒霉蛋？把候选写进去，点一下，转盘说了算。
和市面上大多数在线转盘不同的是：**它不收集任何数据**，选项只存在你自己浏览器的 localStorage 里，服务器只发的静态文件。

## 功能

- ✏️ **选项自己定**：增删改，最多 24 个，自动保存在本地
- 🔗 **分享链接**：选项编码进 URL（`#d=...`），别人打开就是你配置好的转盘
- 🎵 **转动音效**：Web Audio 现场合成，不加载任何音频文件
- 🔁 **不重复模式**：抽过的选项暂时退出，全部抽完自动重置
- 💾 **自带清单**：点「我的」一键载入用户的常吃清单（可继续增删）
- 📱 **移动优先**：手机上单手可操作，文字永远正着不歪
- 🚫 **零后端**：纯 HTML / CSS / JS，无框架、无依赖、无账号
- 🪵 **彩蛋**：新增选项时不填字，这一项会变成「滚木」（梗意：不存在），转盘上直接显示图片

## 本地运行

```bash
npx serve .        # 或 python3 -m http.server 8000
```

打开 `http://localhost:8000/wheel/` 即可。

## 部署

推送到 `main` 分支后，GitHub Actions 会自动构建并部署到 Cloudflare Pages：

```
push → Actions 跑 build.sh 产出 dist/ → wrangler pages deploy → mimichong.pages.dev
```

工作流见 `.github/workflows/deploy.yml`。想手动发布也可以：

```bash
./deploy.sh
```

## 技术说明

- 转盘用 SVG 绘制，扇区按数量均分，颜色由 HSL 色相环自动生成
- 标签位置每帧跟随转盘角度重算，但**不做旋转**，所以任何角度下文字都是水平的
- 动效用 `cubic-bezier` 弹簧曲线，结果弹层从 0.74 倍弹到 1.04 再回落
- 分享数据用 base64url 编码，中文安全（UTF-8 → escape → btoa）
